Before installation

Verify the download

  • Use only an installer supplied directly by the project owner.
  • Confirm that Windows shows the expected verified publisher.
  • Compare the SHA-256 value with the published checksum file.

Installation

Install on Windows

  1. ReceiveUse the complete installer ZIP and checksum supplied directly by the project owner.
  2. VerifyCompare the ZIP's SHA-256 value with the supplied checksum before opening it.
  3. ExtractExtract the complete ZIP to a local folder under Downloads or C:\AAVDS. Do not run setup from inside the ZIP.
  4. InstallDouble-click the AAVDS setup executable and choose whether to create a desktop shortcut. Administrator rights are not required.
  5. StartOpen AAVDS-duct-builder from the Start menu. Projects are stored in Documents\AAVDSProjects and remain available after uninstalling.
