# Product tools

These tools support development and CAD interoperability but are not part of the installed standalone application payload.

- `fusion-join-points/`: adds validated native Fusion joint origins to an imported component.
- `legacy-freecad-macro/`: compatibility launchers for the earlier interactive FreeCAD workflow. They resolve the canonical package from `../../app` when run from this repository.

The Allshield assembly-specific Fusion final exporter is intentionally excluded from this repository.
